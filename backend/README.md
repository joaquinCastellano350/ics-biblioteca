# Backend

Workspace `@ics-biblioteca/backend`. Contendrá la API y las reglas de cuentas, catálogo, préstamos, colas, reservas y notificaciones.

El código de la aplicación irá en `src/`. El framework y los scripts de desarrollo, compilación y pruebas quedan pendientes de definición. La propuesta de datos se encuentra en [el modelo de datos](../docs/modelo-de-datos.md).

Administrar sus dependencias desde la raíz siguiendo el [README del repositorio](../README.md).
