# Frontend

Workspace `@ics-biblioteca/frontend`. Contendrá la interfaz web del catálogo, la cuenta del estudiante, los préstamos y las esperas.

El código de la aplicación irá en `src/`. El framework y los scripts de desarrollo, compilación y pruebas quedan pendientes de definición.

Administrar sus dependencias desde la raíz siguiendo el [README del repositorio](../README.md).
